# Portfolio 2026 Web App

This repository contains a vibrant, animated portfolio website for Shubham Gurav built with Next.js, TypeScript, Tailwind CSS, and GSAP.

## Features
- Multi-page SPA using Next.js `app` router
- Animated navigation and content sections via GSAP
- Responsive interactive skill and project sections
- Session timer widget designed to increase visitor engagement
- Modern dark UI with vibrant gradient accents

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Build for production

```bash
npm run build
npm start
```
